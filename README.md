# Hebrew Learning

Статический учебный веб‑проект по ивриту: таблицы глаголов, предлоги и словарь с озвучкой.

## Как открыть проект

Проект без сборки и бэкенда.

1. Откройте `index.html` в браузере (страница сразу перенаправит на `hebrew.html`).
2. Либо откройте `hebrew.html` напрямую.

## Источник словаря и fallback

Вкладка «Слова» загружает данные из опубликованного Google Sheets CSV.

- Основной источник: публичный CSV Google Sheets.
- При сетевой ошибке/недоступности Google автоматически используется локальный fallback: `words.sample.json`.
- Нормализация данных выполняется в `vocab-data.js` (валидируются обязательные поля `ru` и `he`).

## Ограничения озвучки (Web Speech API)

Озвучка зависит от браузера и ОС:

- набор и качество голосов отличаются между платформами;
- первый запуск звука может требовать пользовательского действия;
- поведение `speechSynthesis` (очередь, паузы, фоновые вкладки) может отличаться в Chrome/Safari/Firefox;
- при строгих сетевых ограничениях может не загрузиться Google CSV, тогда включается локальный fallback.

## Структура файлов

- `index.html` — точка входа/редирект.
- `hebrew.html` — основная разметка приложения.
- `style.css` — стили и адаптив.
- `main.js` — модульная инициализация (подготовлено для будущего включения).
- `tabs.js` — переключение вкладок и sticky-offset.
- `vocab-data.js` — загрузка, парсинг и валидация словаря.
- `vocab-ui.js` — рендер таблицы, blur, highlight, перемешивание.
- `speech.js` — озвучка «всё/одно», random-режим.
- `config.js` — централизованные настройки (интервалы/скорости/blur/cache-buster).
- `words.sample.json` — локальный fallback словарь.
- `script.js` — текущий runtime-файл страницы (в нём активная инициализация UI).

## Ручные контрольные сценарии (smoke-check)

1. Переключение вкладок: «Глаголы / Предлоги / Слова».
2. Загрузка словаря на вкладке «Слова»:
   - нормальный путь (Google CSV),
   - fallback (локальный JSON при недоступности сети).
3. Озвучка:
   - «▶ Озвучить всё»,
   - озвучка одного слова кнопкой `🔊` в строке.
4. Переключатели/действия:
   - `🎲` random-порядок,
   - `Сначала русский` (reverse),
   - `🔀` перемешивание строк.
5. Blur-режим колонок по клику на заголовки (`Иврит / Транскрипция / Русский`).
