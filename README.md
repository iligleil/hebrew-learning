# Hebrew Learning

Небольшой статический веб‑проект для тренировки иврита с тремя разделами:

- **Глаголы** — таблицы-шаблоны спряжений по временам и формам.
- **Предлоги** — таблица предлогов с местоименными суффиксами.
- **Слова** — словарь с озвучкой (иврит/русский), случайным порядком и перемешиванием.

## Быстрый запуск

Проект не требует сборки.

1. Откройте `index.html` в браузере (или `hebrew.html` напрямую).
2. `index.html` сразу перенаправит на основную страницу `hebrew.html`.

## Структура файлов

- `index.html` — точка входа и редирект на основную страницу.
- `hebrew.html` — основная разметка всех вкладок и контролов.
- `style.css` — стили таблиц, вкладок, sticky‑контролов и подсветки.
- `script.js` — логика вкладок, загрузка словаря, озвучка и управление таблицей слов.

## Источник словаря

Слова для вкладки «Слова» загружаются из опубликованного CSV в Google Sheets через `fetch`.

## Ограничения и заметки по озвучке

Озвучка использует **Web Speech API** (`window.speechSynthesis`). Поведение может отличаться по браузерам/ОС:

- состав и качество голосов зависят от платформы;
- некоторые браузеры требуют пользовательское действие перед первым запуском аудио;
- при блокировке сети/доступа к Google Sheets словарь может не загрузиться.

## Ручной smoke-check после изменений

- Переключение вкладок: «Глаголы / Предлоги / Слова».
- Загрузка словаря на вкладке «Слова».
- Озвучка: «▶ Озвучить всё» и «🔊» в строке.
- Переключатель «Случайный порядок».
- Кнопка «🔀» (перемешать строки).
- Переключение «Сначала русский».
- Скрытие/показ колонок по клику на заголовки таблицы.
